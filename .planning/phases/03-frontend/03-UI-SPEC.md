## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gaps, chip internal padding (`px-1.5 py-0.5`) |
| sm | 8px | Inline element spacing (`gap-2`), tag row gaps (`gap-1`) |
| md | 16px | Card padding (`p-4`), section spacing |
| lg | 24px | Page padding on mobile (`p-4`), section vertical gaps (`space-y-6`) |
| xl | 32px | — |
| 2xl | 48px | — |
| 3xl | 64px | — |

Exceptions: Page horizontal padding increases to `sm:p-6` (24px) at the `sm` breakpoint. Touch targets on ✕ and inline text buttons are `px-2 py-1` (8px × 4px) — no 44px minimum enforced (consistent with Demon Registry pattern, same LAN tool constraint).

Source: Demon.tsx page wrapper `p-4 sm:p-6 max-w-3xl mx-auto`

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0c0e12` (`d2bg`) | Page background |

| Accent (10%) | `#c8a84b` (`d2gold`) | See reserved list below |
| Destructive | `text-red-400` / `border-red-900/70` | Delete (✕) button hover state; error feedback text |

**Accent (`d2gold`) reserved for:**
- Page h1 heading text (`text-d2gold`)
- `btn-d2` border and label text
- `chip-d2` tag text and border (`text-d2gold/70 border-d2gold/30`)
- Card gothic corner marks (CSS `::before` via `card-d2`)
- Input/select focus ring (`focus:border-d2gold/50 focus:ring-d2gold/15`)
- Apply success inline feedback: `text-emerald-400` (NOT d2gold — emerald is the success semantic color)

**Semantic colors:**
- Success inline text: `text-emerald-400`
- Error inline text: `text-red-400`
- Muted metadata: `text-slate-500` / `text-slate-600`
- Body text: `text-slate-200` (default body)
- Section labels: `text-slate-400`

Source: `frontend/tailwind.config.ts` color tokens; `index.css` component definitions; Demon.tsx usage.

## Page Structure

**Route:** `/seeds`
**Nav entry:** `{ to: "/seeds", label: "Map Seeds", icon: "🗺️" }` in `NAV_ITEMS`
**Page wrapper:** `<div className="p-4 sm:p-6 max-w-3xl mx-auto animate-fadeIn space-y-6">`

### Section 1: Current Seeds

- **Section heading:** `<h2 className="text-slate-400 text-xs uppercase tracking-widest mb-2">Current Seeds</h2>`
- **Layout:** Compact table rows inside a `card-d2 p-4`. One row per character.
- **Row anatomy:** `Character name · Class` (left, `text-sm text-slate-200`) + `0x7FB203B4` hex seed (right-aligned, `text-xs text-slate-500`) + `[Save Seed]` button (rightmost, `btn-d2 text-xs` or `btn-d2-ghost text-xs`)
- **Inline save form:** Expands below the row on [Save Seed] click. Contains: `<TagInput>` + `input-d2` notes field + `[Save ✓] btn-d2` + `[Cancel]` text button. Only one row can be expanded at a time — opening a second row collapses the first.
- **Empty state (no snapshot):** Plain `card-d2 p-4` with `<p className="text-slate-500 text-sm">No snapshot available. Check In from a device first.</p>`

### Section 2: Seed Library

- **Section heading:** `<h2 className="text-slate-400 text-xs uppercase tracking-widest mb-3">Seed Library{count > 0 && <span className="text-slate-600 font-normal ml-1 normal-case">({count})</span>}</h2>`
- **Layout:** Single-column list of `card-d2 p-4` entries (`space-y-3`).
- **Card anatomy:**
  - Header row: tag chips (`chip-d2`) from `label.split(",")` + ✕ delete button (top-right, `px-2 py-1 text-xs text-slate-600 hover:text-red-400`, `aria-label="Delete seed"`)
  - Notes (if present): `text-slate-500 text-xs mt-1`
  - Metadata: source character + saved date (`text-slate-600 text-xs mt-1`)
  - Apply row: `<span className="text-slate-500 text-xs">Apply to:</span>` + `select-d2 w-auto` character dropdown + `btn-d2 text-xs` [Apply →]
  - Edit button: inline text `"edit"` or pencil — clicking toggles card into edit mode (TagInput pre-filled + notes input pre-filled + [Save ✓] / [Cancel])
  - Success feedback: `<p className="text-emerald-400 text-xs mt-2">Applied to {character}. Sync to device when ready.</p>`
  - Error feedback: `<p className="text-red-400 text-xs mt-2">{error message}</p>`
- **Empty state (no seeds):** `<p className="text-slate-600 text-sm">No seeds saved yet.</p>`

## Interaction Contracts

### D2R Running Guard
- Read from `usePreflight()` hook (already used in Demon.tsx)
- Guard expression: `const d2rRunning = preflight?.pc_running === true || preflight?.deck_running === true`
- Applied to: `[Save Seed]` save button, `[Apply →]` button
- Disabled state: `disabled` attribute + `title="D2R is running — close the game first"`

### Save Seed Flow (inline expand)
1. User clicks `[Save Seed]` on a character row
2. Row expands inline (no modal) with TagInput + notes input + [Save ✓] + [Cancel]
3. If another row is already expanded, collapse it first
4. `[Save ✓]` disabled when: no tags entered, or save mutation pending, or d2rRunning
5. On success: collapse form, no toast needed (success is implicit from form closing)
6. On error: `text-red-400 text-xs` inline error below the form

### Apply Seed Flow (inline per card)
1. User selects character from `select-d2` dropdown (populated from current seeds data)
2. User clicks `[Apply →]`
3. On success: `text-emerald-400 text-xs` inline — `"Applied to {character}. Sync to device when ready."` + sonner toast: `"Applied '{seed_name}' to {character} ({seed_hex})"`
4. On error: `text-red-400 text-xs` inline — display API error message

### Edit Flow (inline card toggle)
1. Clicking `edit` toggles card to edit mode: TagInput (pre-filled) + notes input (pre-filled) + [Save ✓] + [Cancel]
2. `[Cancel]` restores display mode with original values (no mutation)
3. On save success: card snaps back to display mode with updated values; `invalidateQueries` on library list

### Delete Flow
1. Clicking ✕ fires delete mutation immediately — no confirmation dialog (matches Demon Registry)
2. Immediate query invalidation removes card from list

## States and Loading

| State | Behavior |
|-------|----------|
| Loading current seeds | `<p className="text-slate-600 text-sm">Scanning snapshot…</p>` inside `card-d2 p-4` |
| Loading library | `<p className="text-slate-600 text-sm">Loading…</p>` |
| Mutation pending | Disable the triggering button with `isPending` flag; change label to `Saving…` / `Applying…` |
| No snapshot data | Empty state copy (see above) |
| D2R running | Disable save/apply buttons; show tooltip |
